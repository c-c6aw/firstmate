# Live validation: sandboxed importer binds only state/inbox; wake queue moved to state/wake

All runs used the real `bin/` scripts from the gate worktree (target 5509a9e) against disposable lab homes made by `bin/fm-lab-home.sh create`. The fleet-override variables were unset, and every tmux call went through a private `TMUX_TMPDIR` inside the lab. The planner importer's sandbox was a real `bwrap` namespace: the whole filesystem read-only (`--ro-bind / /`) except `$FM_HOME/state/inbox` (`--bind`), with `--clearenv` and `--unshare-pid`. The pre-change comparison ran base e9a6675's `bin/`, extracted with `git archive`. All labs were removed afterwards.
